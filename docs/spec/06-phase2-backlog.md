# 06. 2단계 이후 에피소드 백로그

1단계(토스 Realtime 지원) 완료 후, 같은 시스템 위에 붙일 에피소드들. 지원 직군에 맞춰 골라서 진행한다. 각 에피소드는 착수 시 별도 스펙 문서로 상세화한다.

어필 직군: ◎ 핵심 / ○ 보조

---

## P1. Flink 실시간 집계 — DE◎

- **상황**: 종목별 1분 거래대금·VWAP를 ClickHouse 쿼리가 아니라 스트림에서 바로 계산
- **할 일**: Flink DataStream(Java)으로 `executions` 토픽 소비 → 텀블링 윈도우 집계 → 결과 토픽/ClickHouse
- **핵심 실험**: 체크포인트 + Kafka 트랜잭션 싱크로 exactly-once 구성, 작업 강제 종료 후 복구 시 집계값 정확성 검증. 늦게 도착한 이벤트(워터마크) 처리
- **토스 Realtime 인터뷰 전 최우선**

## P2. Kafka 메시지 키 재설계 — DE◎ BE◎

- **상황**: Debezium 기본 키(PK)로는 같은 계좌의 이벤트 순서가 보장되지 않음
- **할 일**: SMT로 키를 `account_id` 또는 `symbol`로 재설정, 각각의 순서 보장 범위와 파티션 쏠림 비교
- **핵심 실험**: 04 스펙 E5(핫 파티션), DLQ 토픽과 재처리 전략

## P3. Redis 잔고 캐시와 정합성 — BE◎ DE○

- **상황**: 보유 잔고 조회가 잦아 Redis 캐시 적용 → 체결 후 캐시가 stale해지는 문제
- **할 일**: Cache-aside 적용 → 갱신 경합 재현(동시 체결 시 오래된 값이 캐시에 남는 상황) → **CDC 이벤트 구독으로 캐시 무효화**하는 방식과 비교
- **측정**: 조회 p95, stale 응답 비율

## P4. 로컬 캐시 — BE◎

- **상황**: 거의 변하지 않는 종목 마스터를 매 요청마다 DB 조회
- **할 일**: Caffeine 적용, TTL·최대 크기 설정, 다중 인스턴스에서의 불일치 문제와 대응(짧은 TTL vs 이벤트 기반 무효화) 정리
- **측정**: 응답시간, DB 쿼리 수 감소

## P5. 동기/비동기 분리 + Transactional Outbox — BE◎ DE○

- **상황**: 체결 후 알림·내역 기록 같은 부가 작업이 주문 처리 응답을 늦춤
- **할 일**: 반드시 동기여야 하는 것과 아닌 것을 구분 → `@Async` 방식과 Outbox 테이블 + Debezium 방식 비교. 부가 작업 실패 시 유실 여부가 핵심 차이
- **측정**: 주문 API 응답시간, 장애 시 이벤트 유실 여부

## P6. Netty 기반 SSE 체결 알림 — BE◎ Infra○

- **상황**: 사용자에게 체결 알림을 실시간 푸시
- **할 일**: Spring WebFlux(Netty) SSE 엔드포인트가 Kafka `executions` 토픽 구독 → 계좌별로 라우팅. 하트비트, 재연결 시 `Last-Event-ID`로 누락 이벤트 재전송
- **측정**: 동시 연결 수(k6 또는 별도 클라이언트) 증가에 따른 메모리·지연, 느린 클라이언트로 인한 backpressure 처리

## P7. JVM 메모리·GC 분석 — BE◎ Infra◎

- **상황 (재현 실험)**: 부하 시 order-server 또는 컨슈머의 응답 지연이 튀는 현상
- **할 일**: GC 로그 활성화(`-Xlog:gc*`), `jstat`, 힙 덤프 분석 → 힙 크기·G1 파라미터(`MaxGCPauseMillis` 등) 조정 전후 비교. 일부러 메모리를 많이 쓰는 코드 경로를 만들어 재현해도 됨 (명시할 것)
- **측정**: GC pause p99, 처리량, 응답 p99

## P8. tcpdump 네트워크 장애 분석 — Infra◎ BE○

- **상황 (재현 실험)**: 컨테이너 간 네트워크 지연·패킷 손실 시 Kafka 프로듀서 타임아웃 발생
- **할 일**: `tc netem`으로 지연/손실 주입 → `tcpdump`로 캡처, Wireshark로 재전송·RST 패턴 분석 → 프로듀서 타임아웃·재시도 설정 조정으로 대응
- **측정**: 에러율, 재전송 비율, 설정 조정 전후 비교
